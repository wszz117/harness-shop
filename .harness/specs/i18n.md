# Domain: i18n

> 国际化域：默认中文（zh），支持英文（en）。语言优先级：**会话内显式切换 > 用户级偏好(User.uiLanguage) > 访客级 localStorage > 默认 zh**。

## Requirement: 全站语言切换 (I18N-R-001)

### Scenario: 顶栏切换语言即时生效 (I18N-S-001)
- GIVEN 页面以中文渲染
- WHEN 用户点击顶栏语言切换（中/EN）
- THEN 全站导航、按钮、提示文案立即切换为英文，无需刷新
- AND 本次会话标记显式切换（sessionStorage `uiLanguageSessionExplicit`）

### Scenario: 访客语言持久化 (I18N-S-002)
- GIVEN 访客切换为英文
- WHEN 刷新页面
- THEN 界面保持英文（localStorage `uiLanguage`）

### Scenario: 登录语言合流 (I18N-S-003)
- GIVEN 访客本会话已显式切换为英文；账号偏好为中文
- WHEN 该账号登录
- THEN 界面保持英文（会话显式选择优先）；若本会话未显式切换过，则应用账号偏好（见 memory: login-overwrites-guest-uiLanguage）

## Requirement: 内容双语 (I18N-R-002)

### Scenario: 商品字段按语言投影 (I18N-S-004)
- GIVEN 商品含 name/description（中文）与 name_en/description_en（英文）
- WHEN 前端以 `x-ui-language: en` 请求商品接口
- THEN 返回投影后的英文 name/description；英文字段缺失时回退中文
- AND 前端词典 en 覆盖所有 zh key（EN 覆盖率检查）

### Scenario: 后端错误消息键 (I18N-S-005)
- GIVEN 后端校验失败（如管理端非法数值）
- WHEN 返回错误响应
- THEN 响应含稳定 `messageKey`（如 `admin.product.invalidInput`），由前端按当前语言渲染文案
